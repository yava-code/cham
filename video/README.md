# video inserts

Standalone 1920x1080 animation pages for OBS. Open in a browser at 100% zoom
(F11 for fullscreen) and capture the window with a Window or Browser source.

| file | use |
|---|---|
| 01-intro.html | title card |
| 02-problem.html | vibe-coding problem and the research numbers |
| 03-dataflow.html | request, need, save, answer |
| 04-errors.html | one error in en, uk, ru, typed out |
| 05-vocabulary.html | the ten words |
| 06-outro.html | repo URL |
| 07-lower-third.html | name bar; `?t=Title&s=Subtitle` sets the text |

Keys: **R** or click replays, **T** toggles a transparent background (for
overlays on screen recordings; in OBS a Browser source also keeps alpha),
**H** hides the hint. Add `#rec` to the URL to start with the hint hidden,
`#clear` for transparent. Each file works from disk, no server needed.
